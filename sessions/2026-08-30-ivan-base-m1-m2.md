## TL;DR
Arranque del proyecto: motor que "entiende" un video en batch + un loop interactivo
donde escribes un prompt y ves el corte en el navegador. Quedaron entregados y probados
**M1 (CLI)** y **M2 (web)**. Todo local y ligero (sin torch). Falta que Mauricio conecte
las credenciales de AWS/Bedrock; mientras tanto hay un **modo prueba sin IA** para usarlo ya.

## Qué se hizo
- **Motor batch** (`haku/`): detección de shots (scenedetect), transcripción
  (faster-whisper, sin torch), señales visuales baratas con OpenCV (brillo, saturación,
  proxy de movimiento, duración), timecode frame-accurate al fps real, e índice
  `index.json` con `{shot_id, in_frame, out_frame, in_tc, out_tc, transcript, señales}`.
- **Decisión** (`haku/decide.py`): prompt → Claude en Bedrock → rangos ordenados,
  **validados contra el índice** (imposible inventar shots; los in/out los manda el índice).
- **Timeline + render**: OTIO con `RationalTime` a fps reales (`.otio`) → ffmpeg → `salida.mp4`.
- **M1 CLI** (`cli.py`): un comando de punta a punta.
- **M2 web** (`server/`): FastAPI + UI mínima (elegir video, ver shots, prompt, reproducir).
- **Persistencia**: SQLite vía SQLAlchemy (migrar a Postgres = cambiar `HAKU_DB_URL`).
- **Setup reproducible**: `requirements.txt` fijado, `setup.sh` de un comando, `.env.example`.
- **Modo prueba sin AWS**: `HAKU_DECIDE_BACKEND=fake` (decisión heurística local).
- **Pruebas**: 71 en verde (timecode reversible + validación que rechaza shots inventados).

## Decisiones clave (y por qué)
- **Frontera batch / interactivo** — la mitad online NUNCA corre visión ni reprocesa video;
  solo lee el índice y arma OTIO. Es lo que hace posible que se sienta instantáneo.
- **Sin torch por ahora** — BLIP/YOLO/CLIP se difieren a M3; el índice usa señales baratas.
- **Claude siempre por Bedrock (Converse API)** con `BEDROCK_MODEL_ID` en env, auth AWS
  estándar (no API key). Cliente compartido en `haku/bedrock_client.py`.
- **ffmpeg vía `imageio-ffmpeg`** (binario por pip) — no hay ffmpeg de sistema en el Mac
  y así los dos tenemos el mismo. OTIO se **compila** desde sdist (necesita Xcode CLT).
- **Validar la decisión contra el índice** — red de seguridad contra alucinaciones del modelo.

## Cómo probar
```bash
# Setup (una vez)
./setup.sh
source .venv/bin/activate

# Sin credenciales AWS todavía -> modo prueba:
export HAKU_DECIDE_BACKEND=fake
# mete un video (con audio) en data/videos/ y:
uvicorn server.main:app --reload    # http://127.0.0.1:8000
# o por terminal:
python cli.py data/videos/tu_video.mp4

# Cuando haya AWS: verificar Bedrock y usar Claude de verdad
python scripts/check_bedrock.py
export HAKU_DECIDE_BACKEND=bedrock
```
